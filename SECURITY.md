# Безопасность

- Используйте отдельный случайный секрет для каждого пользователя: `openssl rand -hex 16`.
- Для fake-TLS нужен реальный TLS 1.3 `mask_host` на порту 443.
- Для TLS-only режима установите `enable_secure: false`.
- Не включайте `ignore_time_skew` без необходимости.
- Храните `config.json` и Telegram-ссылки вне общих логов и репозитория.

Fake-TLS не скрывает IP, размеры пакетов и время соединений. При `match_mask_host: false` длина fake-certificate может отличаться от ответа mask-host. Автоматической ротации IP и middle-proxy режима нет.

Обход блокировок не гарантируется. Проверяйте работу в своей сети и обновляйте код при изменении протокола Telegram.
